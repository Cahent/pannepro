# Panne-pro · MVP 0.1

Laravel 13 Overlay für das Status- und Verfügbarkeitsportal deutscher LKW-Pannendienste.

**Enthält:** Kundenlogin und Registrierung, Admin-UI für Firmen und Geräte, vier Regionen, Server-Dashboard mit Polling, verschlüsselt speicherbare Geräte-Bearer-Token (SHA-256 Hash), REST-Status-Endpunkt mit Heartbeat-Auswertung, Statushistorie, Arduino-Display-Skizze (UI-Prototyp), API-Testskript.

**Noch nicht enthalten:** Laravel Framework, Composer-vendor, fertige produktive Arduino-TLS-Übertragung, exakte Geokarte, E-Mail-Verifikation, Mandanten-Verwaltung, Gerätesperrung. Daher noch **kein vollständig produktionsfertiger Dienst**.

Setup: siehe **INSTALLATION.md**. Architektur: PHP 8.3 / Laravel 13 / MariaDB.
